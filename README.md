# MixCasete
# 🎵 Mix.Casete Reproductor retro estilo cassette que busca y reproduce música de YouTube sin cuenta. GitHub Actions compila el APK automáticamente.  ## Descargar APK - Cada push → pestaña **Actions** → run → **Artifacts** → `MixCasete-debug-apk` - Tags `v*` → pestaña **Releases** → APK adjunto
